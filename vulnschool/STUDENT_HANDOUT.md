# STUDENT HANDOUT - VulnSchool

## Tujuan Praktikum
Aplikasi ini disediakan untuk latihan menemukan, mengeksploitasi, dan memperbaiki kerentanan web dalam lingkungan lab terkontrol.

## Akun Default
- Admin: `admin / admin123`
- Dosen: `dosen1 / dosen123`
- Mahasiswa: `mhs001 / mhs123`

## Endpoint Utama
- Login: `/login`
- Dashboard: `/dashboard`
- Nilai Mahasiswa: `/mahasiswa/nilai`
- Pengumuman: `/pengumuman`

## Tools yang Disarankan
1. Browser DevTools
2. Burp Suite Community
3. Postman / curl
4. SQLMap (sesuai instruksi dosen)

## Rules of Engagement
1. Hanya uji pada lingkungan VulnSchool lab.
2. Dilarang menyerang sistem di luar scope praktikum.
3. Simpan bukti pengujian (payload, request, response).
4. Jika menemukan bug di luar modul praktikum, laporkan ke dosen.
